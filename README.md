# Snake Game in C++

A simple Snake Game developed using C++ programming language. The game allows the player to control a snake, collect food, and increase score while avoiding collisions.

---

## 🎮 Features

- Snake movement control
- Food generation
- Score tracking
- Collision detection
- Console-based gameplay

---

## 🛠️ Technologies Used

- C++
- Functions
- Loops
- Conditional Statements

---

## 📂 Project Structure

snake-game-cpp/

├── src/ → Source code  
├── bin/ → Executable application  
├── docs/ → Code explanation document  
├── images/ → Output screenshots  
└── README.md → Project information

---

## ▶️ How to Run

1. Open the project
2. Run the executable file from `bin/`
3. Play the game using keyboard controls
